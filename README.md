# 🛺 Rickshaw Lagbe?
Uber-style ride booking web app for rickshaw, battery rickshaw, CNG auto, easy bike and moto (Dhaka). Pure HTML/CSS/JS + Leaflet.

Features: OTP login (demo 1234), map pickup/drop, fare estimate per vehicle, promos, bKash/Nagad/Cash/Wallet, schedule ride, driver matching + live tracking, PIN, call/chat/share/SOS, rating & tip, ride history, saved places, wallet, driver mode.

Deploy: Render Static Site, publish dir `.`, no build command.
